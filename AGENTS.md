# Работа над «Атласом нейросетей»

- Начинайте работу с отдельной ветки от актуальной `main`. Предлагайте изменения через PR. Слияние и публикация сайта требуют явного разрешения владельца.
- Для задач по документации ограничивайте diff файлами документации. Меняйте `index.html`, `og.png` и записи каталога только при явном запросе на соответствующее изменение.
- При обновлении каталога сверяйте характеристики сервисов по первоисточникам. Сохраняйте уникальность идентификаторов записей, используйте существующие категории и проверяйте число сервисов в метаданных и тексте страницы.
- При изменениях интерфейса откройте `index.html` в браузере. Проверьте поиск, фильтры, карточки и работу на узком экране. Для документации проверьте команды, имена файлов и список изменений в diff.
- В описании PR укажите, что изменилось и какие проверки выполнены.
