# Атлас нейросетей

Русскоязычный справочник по ИИ-сервисам. Интерактивная карта, поиск и фильтры помогают найти подходящий инструмент. В карточках указаны возможности сервиса, совместимые инструменты и ограничения.

## Запуск

1. Клонируйте репозиторий или распакуйте ZIP, скачанный через **Code → Download ZIP**.
2. Откройте `index.html` в браузере. Установка зависимостей, ключи API и сборка не требуются. Для загрузки шрифтов Google Fonts нужен интернет, при его отсутствии используются запасные шрифты.
3. Для проверки введите «Яндекс» в поиск, выберите категорию и откройте карточку из списка или с карты.

## Файлы

- `index.html` содержит разметку, стили, JavaScript и записи каталога.
- `og.png` используется для предпросмотра ссылки на сайт.
- `AGENTS.md` описывает порядок работы над проектом.
